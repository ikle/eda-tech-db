# Global Parameters

* unit  — Layout Grid (nm);
* gate  — Drawn Gate Length (in units);
* sx    — Horizontal Pin Grid (in units);
* sy    — Vertical Pin Grid (in units);
* power — Cell Power and Ground Rail Width (in units);
* pu    — AC Power Unit Order (value = x * 10^pu μW/MHz);
* cu    — Pin Capacitance Unit Order (value = x * 10^cu pF).

# Cell Sizes

* cell    — Cell Type;
* variant — Cell Variant;
* height  — Cell Height in global.sy units;
* width   — Call Width in global.sx units.
